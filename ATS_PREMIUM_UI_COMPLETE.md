### **Typography:**
```css
Headings: font-semibold text-white
Body: text-white/80
Labels: text-white/70 uppercase tracking-wide
Muted: text-white/60
Subtle: text-white/50
```

### **Spacing:**
```css
Card Padding: p-5
Gap: gap-4 (cards), gap-3 (elements)
Rounded: rounded-2xl (cards), rounded-xl (buttons)
Icons: h-4 w-4 (small), h-5 w-5 (medium), h-6 w-6 (large)
```

### **Effects:**
```css
Hover: hover:-translate-y-0.5
Transition: transition-all duration-300
Shadow: shadow-xl, shadow-2xl
Blur: backdrop-blur-sm
Gradient: linear-gradient(135deg, ...)
```
